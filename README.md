# 발표 기반 질의응답 평가 (Trace)

「인공지능 윤리」 수업의 학생 발표에서 주제와 개념을 파악해 맞춤 질문을 만들고, 질문에 대한 답변만을 근거로 개념 7개와 원칙 간 관계 10개의 이해 수준을 판정하는 교수자용 웹앱입니다.

서버 없이 브라우저에서만 동작하므로 GitHub Pages에 그대로 올려 쓸 수 있습니다.

## 쓰는 법

1. 페이지를 열고 오른쪽 위 **⚙ 설정**에서 본인의 baze API 키를 입력합니다.
2. 탭 2에서 강의를 고르고, 탭 3에서 발표를 입력합니다(샘플로 시험해 볼 수 있습니다).

## 데이터는 어디에 저장되나

- API 키, 강의, 직접 만든 채점기준표: 이 브라우저의 localStorage
- 평가 기록, 음성·pdf 원본: 이 브라우저의 IndexedDB

서버로 보내는 곳은 baze API(`api.baze.co`)뿐입니다. 다른 브라우저나 컴퓨터에서는 기록이 보이지 않으니, 필요한 기록은 탭 6의 **내보내기**로 JSON 파일을 받아 두세요. API 키가 브라우저에 남으므로 공용 컴퓨터에서는 쓰지 마세요.

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 |
| `js/core.js` | 판정 규칙(LLM 없음) |
| `js/llm.js` | baze 호출과 프롬프트 |
| `js/api.js` | 저장과 평가 진행 |
| `채점기준표/` | 기본 채점기준표 원본(md)과 앱이 읽는 변환본(json) |
| `자료/샘플 발표 자료/` | 시험용 샘플. 샘플을 추가하면 `samples.json`에 이름도 넣습니다 |
| `tests/test_core.js` | 규칙 테스트: `node tests/test_core.js` |

샘플 자료의 학교·학과 정보와 개인정보는 가렸습니다.
